# 안전 설계

숨쉬는 동화는 아이가 탄 차의 공조·조명·시트를 움직입니다. 그래서 차량 제어는 모두 한 곳(`SafetyGuard`)을 거치고, 다음 세 가지를 지킵니다.

1. **차가 멈춰 있을 때만** 연출합니다.
2. **정해진 범위 안에서만** 차량 값을 바꿉니다.
3. 연출이 끝나거나 중단되면 **시작 전 상태로 되돌립니다.**

코드는 `domain/.../domain/safety/`에 있습니다. 순수 Kotlin이라 에뮬레이터 없이 `./gradlew :domain:test`로 검증합니다.

## 1. 연출 시작·중단 조건

### 시작 조건
아래를 **모두** 만족해야 연출을 시작합니다. 아직 값을 받지 못한 조건은 만족하지 않은 것으로 봅니다.

| 조건 | 출처 | 깨졌을 때 이유 (`NotParkedReason`) |
|---|---|---|
| 주행 중 UX 제한 없음 | AAOS `CarUxRestrictionsManager` | `UX_RESTRICTED` |
| 기어 P | AAOS 차량 속성 | `NOT_IN_PARK` |
| 속도 0 (절댓값 0.1 m/s 미만, `NaN`은 주행으로 봄) | AAOS 차량 속성 | `MOVING` |
| 모든 도어 닫힘 | Pleos Vehicle SDK | `DOOR_OPEN` |

주차 브레이크는 시작 조건이 아닙니다. EV 충전 대기처럼 기어를 P에 두고 주차 브레이크는 걸지 않는 상황이 흔하기 때문입니다.

### 연출 중 중단
연출 중에는 위 조건을 계속 감시하고, 하나라도 깨지면 **즉시 중단하고 복원**합니다. 여기에 한 가지가 더해집니다.

- 연출 중 주차 브레이크가 **걸려 있다가 풀리면** `PARKING_BRAKE_RELEASED`로 중단합니다. 다시 걸어도 그 연출은 이어지지 않고, 새로 시작해야 합니다.

화면은 `NotParked.reasons`에 담긴 이유로 "문을 닫아 주세요" 같은 안내를 보여 줍니다.

### 오디오 포커스
내비 안내나 전화로 오디오 포커스를 잃으면 소리, 효과 진행, 아이 참여 대기를 모두 **일시정지**합니다. 이때는 중단이 아니라서 실내 상태는 그대로 둡니다. 처음부터 포커스를 얻지 못하면 시작하지 않습니다.

## 2. 차량 제어 허용 범위

동화 대본은 차량과 무관한 추상 값(`fanLevel`, `temperatureDelta` 등)만 씁니다. `SafetyPolicy`가 그 값을 차량이 알려 준 지원 범위(`check…Capabilities`)와 아래 상한에 맞춰 실제 값으로 바꿉니다. 상한은 `SafetyLimits`에 모여 있습니다.

| 효과 | 차량 값 | 규칙 |
|---|---|---|
| `fanLevel` 0~5 | 풍량 | 최대 풍량의 **80%**를 위쪽 끝으로 나눔. 0단계는 최저 풍량 (바람을 멈추려면 전원을 꺼야 하므로) |
| `temperatureDelta` | 영역별 설정 온도 | 시작 온도 기준 상대값. **20~26℃**, 시작값 **±2℃**, 차량 범위 안으로 줄이고 차량 단위(0.5℃)에 맞춤 |
| `seatHeat` | 뒷좌석 열선 | 최대 **1단** |
| `seatLift` | 조수석 높이 | 아래 4장 참고 |
| `ambient` | 무드등 색·밝기 | 색은 그대로, 밝기는 0~1을 차량 범위로 |
| `fanDirection` | 풍향 | 그대로 |
| `cabinLight`, `spotlight` | 실내등, 독서등 | 켜기·끄기. 시작 상태를 읽을 수 있을 때만 바꿈 |

온도는 줄인 결과가 요청과 반대 방향이 되면 바꾸지 않습니다. 예를 들어 시작이 27℃인데 "따뜻하게 +1"을 요청하면 26℃ 상한 때문에 오히려 내려가므로 그대로 둡니다.

**창문은 제어하지 않습니다.** 아이 손이 끼일 수 있어서 바람은 공조 풍량·풍향으로만 표현합니다. 차량 포트(`VehicleEffectPort`)에 창문 메서드 자체가 없습니다.

### 연출 강도
부모가 고르는 강도는 허용 범위의 위쪽 끝(풍량)이나 요청 값(온도 변화, 밝기)에 곱합니다. 가장 강하게 골라도 허용 범위를 넘지 않습니다.

| 강도 | 배율 |
|---|---|
| 약 | 0.5 |
| 중 | 0.75 |
| 강 | 1.0 |

열선은 1단이 가장 약한 단계라 강도를 곱하지 않습니다.

## 3. 상태 저장과 복원

`SafetyGuard`는 연출 한 번을 세 단계로 다룹니다.

1. **`begin`**: 정차가 아니면 아무것도 바꾸지 않고 거절합니다. 정차면 차량 지원 범위와 현재 실내 상태를 저장합니다. 공조 전원이 꺼져 있었다면 켠 직후, 아무것도 바꾸기 전에 다시 읽어 기준값으로 씁니다.
2. **`apply`**: 효과를 보내기 직전마다 정차를 다시 확인하고, 허용 범위로 줄인 값만 차량에 보냅니다. 무드등을 서서히 바꾸는 전환(`applyAmbientFade`)도 중간값을 보낼 때마다 같은 확인을 거칩니다.
3. **`restore`**: 저장한 값으로 되돌립니다.
   - 순서: 풍량 → 풍향 → 온도 → 무드등 → 열선 → 실내등·독서등 → (처음에 꺼져 있었다면) 공조 전원 끔. 전원을 끄면 다른 값을 바꿀 수 없어 전원은 마지막입니다.
   - 호출한 작업이 취소돼도 `NonCancellable`로 끝까지 실행합니다.
   - 한 항목이 실패해도 나머지를 계속하고, 실패한 항목 이름을 돌려줍니다.
   - 시작 때 읽지 못한 항목은 건드리지 않았으므로 되돌리지도 않습니다.

`apply`와 `restore`가 동시에 들어오면 `Mutex`로 차례대로 처리합니다. 연출이 정상 종료·중단·취소 중 어떻게 끝나든 재생 엔진(`PlayStoryUseCase`)은 소리를 먼저 끄고 `restore`를 부릅니다.

## 4. 시트 움직임

동화의 흔들리는 장면에서 조수석을 살짝 올렸다 내립니다. 가장 조심스럽게 다루는 효과라서 조건이 많습니다.

- **부모 설정에서 켠 경우만** 동작합니다. 기본값은 꺼짐입니다.
- **조수석만**, 그리고 **어른이 앉아 안전벨트를 맨 경우만** 움직입니다. 운전석은 출발 직전 자세가 바뀌지 않도록 움직이지 않습니다.
- **연출마다 한 번**만 씁니다. 그 한 번 안에서 올렸다 되돌리기를 대본의 `repeat`만큼, **최대 3번** 되풀이합니다.
- 한 번 올릴 때 **최대 1초, 높이 범위의 10%**까지 올립니다.
- 다시 올리기 전에 매번 **시작 위치로 돌아온 것을 확인**합니다. 아래 방향은 시작 위치로 돌아갈 때만 쓰고, 시작 위치보다 내리지 않습니다.
- SDK의 시트 이동은 연속 이동(위·아래·멈춤)이라 위치를 읽으며 멈추고, 시간 상한으로 반드시 멈춤 명령을 보냅니다.
- 올리는 중 정차가 깨지거나 취소되면 바로 멈추고 이번 회차만 되돌립니다.

건너뛰거나 실패한 경우는 결과(`SeatLiftOutcome`)로 남깁니다.

| 결과 | 뜻 |
|---|---|
| `DONE` | 올렸다가 시작 위치로 되돌림 |
| `DISABLED` | 부모 설정에서 꺼져 있음 |
| `ALREADY_USED` | 이번 연출에서 이미 씀 |
| `UNSUPPORTED` | 차량이 시트 높이 조절을 지원하지 않음 |
| `NOT_OCCUPIED` | 조수석에 앉아 벨트를 맨 사람이 없음 |
| `POSITION_UNREADABLE` | 위치를 읽지 못함 |
| `AT_TOP` | 이미 맨 위라 올릴 곳이 없음 |
| `UNRESTORED` | 올렸는데 제자리로 되돌리지 못함. 부모에게 알림 |

### 위치를 읽을 수 있는 차에서만
위치를 모르면 시작 위치로 돌아왔는지 확인할 수 없으므로 움직이지 않습니다.

- **실차 SDK**: 0은 맨 아래로 믿고 동작합니다.
- **에뮬레이터 SDK**: 실제 위치와 관계없이 늘 0을 돌려줍니다. 어댑터가 이 값을 "읽지 못함"으로 바꿔 건너뜁니다.
- **debug 빌드의 시연 모드**: 위치와 착석을 Virtual Console에서 읽습니다. 에뮬레이터에는 벨트 정보가 없어 착석으로 대신합니다(`EmulatorSeatState`). 시연 모드는 release 빌드에서 켤 수 없고, SDK가 0·false를 돌려줄 때만 끼어듭니다.

## 5. 알려진 한계

- **앱 프로세스가 강제로 종료되면 복원되지 않습니다.** 복원은 앱 안에서 실행되므로, 연출 중 앱이 죽으면(재설치, 시스템 종료 등) 바꾼 공조·조명 값이 남습니다. 개발 중에는 앱을 다시 설치하기 전에 연출을 먼저 멈춰 주세요. 저장한 상태를 기기에 남겨 다음 실행 때 되돌리는 방법을 검토하고 있습니다.

| `SafetyGuardTest` | 저장·복원 순서, 취소 중 복원, 실패 항목 보고, 창문 효과 없음, 무드등 전환의 시작·끝 값 |
