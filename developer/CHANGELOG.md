# 변경 기록

버전은 `app/build.gradle.kts`의 `versionName`을 따릅니다.

## 다음 버전 (작업 중)

### 추가
- 무드등 전환: `ambient`의 `fadeSec` 동안 지금 조명에서 목표 색·밝기로 서서히 바꿉니다. `restore`의 `fadeSec`도 무드등을 시작 전 조명으로 서서히 돌린 뒤 복원합니다.
- `ambientBrightnessStep`에 `fadeSec`를 추가했습니다. 「해님과 바람」 숨 맞추기의 들이쉬기에서 3.5초 동안 서서히 밝아집니다.
- 공개 개발자 문서(`developer/`)

## 0.1.0 (2026-11-03)

첫 출품 빌드입니다.

### 동화
- 「해님과 바람, 그리고 작은 차의 나그네」 (장면 12개, 약 8분)
- 대사 음원 110개 (Qwen3-TTS), 장면 일러스트 12장과 표지 (FLUX.1-schnell), 효과음 직접 합성
- 아이 이름 부르기 (Pleos TTS), 가족 대화 카드

### 차량 연출
- 공조 풍량·풍향·온도, 무드등 색·밝기, 실내등·독서등, 뒷좌석 시트 열선
- 조수석 시트 들썩임 (부모 설정에서 켠 경우만)
- 정차 시에만 시작, 정차가 깨지면 즉시 중단하고 시작 전 상태로 복원
- SafetyGuard 허용 범위: 온도 20~26℃·시작값 ±2℃, 풍량 최대 80%, 열선 1단
- 연출 강도 약·중·강

### 아이 참여
- 외치기 (Pleos STT, 자모 단위 느슨한 키워드 판정), 숨 불기 (마이크 음량), 숨 맞추기
- 모든 참여에 대체 버튼, 반응이 없으면 시간 초과 뒤 계속

### 재생
- 오디오 포커스 손실 시 일시정지 (내비 안내·전화)
- 부모 일시정지·재개·그만하기·장면 건너뛰기

### 개발 도구 (debug 빌드만)
- Fake 차량과 조작 패널, SDK 확인용 화면
- 시연 모드: 안전 장치 HUD("동화 요청 → 차량에 보낸 값"), 에뮬레이터 시트 위치를 Virtual Console에서 읽기

### 알려진 문제
- 연출 중 앱 프로세스가 강제 종료되면 실내가 복원되지 않습니다.
- 에뮬레이터 SDK는 시트 위치를 늘 0으로 읽어 시트 들썩임을 건너뜁니다 (시연 모드에서는 동작).
