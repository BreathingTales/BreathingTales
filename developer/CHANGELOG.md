# 변경 기록

버전은 `app/build.gradle.kts`의 `versionName`을 따릅니다.

## 다음 버전 (작업 중)

### 추가
- (debug 전용) 시연 HUD가 시트 들썩임을 움직이는 동안 보여 줍니다. 높이·방석 기울기마다 시작 위치·올릴 수 있는 범위·지금 위치를 게이지로 그리고, 올림·되돌림·멈춤을 색과 글자로 표시합니다.
- 시트 들썩임에 방석 기울기를 더했습니다. 차가 지원하면 높이와 함께 방석 앞쪽도 범위의 10%까지 올려 몸이 살짝 뒤로 기울고, 두 축 모두 시작 위치로 되돌린 것을 확인한 뒤 다시 올립니다. 등받이는 뒷좌석 쪽으로 움직이므로 쓰지 않습니다.
- 무드등 전환: `ambient`의 `fadeSec` 동안 지금 조명에서 목표 색·밝기로 서서히 바꿉니다. `restore`의 `fadeSec`도 무드등을 시작 전 조명으로 서서히 돌린 뒤 복원합니다.
- `ambientBrightnessStep`에 `fadeSec`를 추가했습니다. 「해님과 바람」 숨 맞추기의 들이쉬기에서 3.5초 동안 서서히 밝아집니다.
- 공개 개발자 문서(`developer/`)
- (debug 전용) 오디오 포커스 손실을 만드는 `FocusStealReceiver`(내비 안내·통화·다른 미디어), 시트를 움직이지 않고 SDK 값만 읽는 확인 화면 모드(`--ez seatRead true`), 방석 기울기·등받이와 높이를 함께 움직여 보는 확인 화면 모드(`--ez seatSway true`)
- 열선이 없는 차에서 이야기 전체가 이어지는지 확인하는 단위 테스트

### 고침
- 시트 명령의 응답이 늦으면(에뮬레이터 첫 명령은 약 0.9초) 시트가 1초 상한보다 오래 올라갈 수 있던 문제. 시간을 응답을 받은 때가 아니라 명령을 보내기 시작한 때부터 잽니다.
- 연출 중 기어를 P에서 바꾸면 실내등·독서등을 되돌리지 못하던 문제. 차가 P가 아니면 등 스위치를 거부하므로, 다시 정차하는 순간 되돌립니다. 그 전에 다음 이야기를 시작하면 그 이야기가 끝날 때 처음 상태로 되돌립니다.

### 변경
- 연출 강도별 바람의 위쪽 끝을 최대 풍량에 배율을 곱하는 대신 차량의 최저 풍량과 허용 풍량(최대의 80%) 사이에서 잡습니다 (약 1/3, 중 1/2, 강 허용 풍량). 풍량 1~8 차에서는 지금과 같고(3·4·6), 최저 풍량이 높은 차에서 약 강도의 바람이 최저 풍량에 붙지 않습니다.
- 착석·안전벨트 영역 조회를 SDK 2.3.2에서 deprecated된 형태 대신 `CapabilityConfig`를 함께 받는 형태로 바꿨습니다. 읽는 차량 속성은 같습니다.
- 제출용 release APK를 `apk/BreathingTales_BreathingTales_release.apk`에 두고, README에 실행 방법·테스트 환경·APK 위치를 적었습니다.
- release 서명 키를 새로 만들었습니다 (인증서 SHA-256 `85e1750f…5e6ad5d`). 이전 키로 서명한 APK와는 서명이 달라, 설치된 앱을 지우고 다시 설치해야 합니다.

## 0.1.0 (2026-11-03)

첫 출품 빌드입니다.

### 동화
- 「해님과 바람, 그리고 작은 차의 나그네」 (장면 12개, 약 8분)
- 대사 음원 110개 (Qwen3-TTS), 장면 일러스트 12장과 표지 (FLUX.1-schnell), 효과음 직접 합성
- 아이 이름 부르기 (Pleos TTS), 가족 대화 카드

### 차량 연출
- 공조 풍량·풍향·온도, 무드등 색·밝기, 실내등·독서등, 뒷좌석 시트 열선
- 조수석 시트 들썩임 (부모 설정에서 켠 경우만)
- 정차 시에만 시작, 정차가 깨지면 즉시 중단하고 시작 전 상태로 복원
- SafetyGuard 허용 범위: 온도 20~26℃·시작값 ±2℃, 풍량 최대 80%, 열선 1단
- 연출 강도 약·중·강

### 아이 참여
- 외치기 (Pleos STT, 자모 단위 느슨한 키워드 판정), 숨 불기 (마이크 음량), 숨 맞추기
- 모든 참여에 대체 버튼, 반응이 없으면 시간 초과 뒤 계속

### 재생
- 오디오 포커스 손실 시 일시정지 (내비 안내·전화)
- 부모 일시정지·재개·그만하기·장면 건너뛰기

### 개발 도구 (debug 빌드만)
- Fake 차량과 조작 패널, SDK 확인용 화면
- 시연 모드: 안전 장치 HUD("동화 요청 → 차량에 보낸 값"), 에뮬레이터 시트 위치를 Virtual Console에서 읽기

### 알려진 문제
- 연출 중 앱 프로세스가 강제 종료되면 실내가 복원되지 않습니다.
- 에뮬레이터 SDK는 시트 위치를 늘 0으로 읽어 시트 들썩임을 건너뜁니다 (시연 모드에서는 동작).
